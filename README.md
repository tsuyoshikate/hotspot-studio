# 热点营销工作台(西班牙语机构版 · HotSpot Studio)

五步流水线:新闻抓取(带风险识别)→ 建议匹配商品 + 客户画像 → 商品库手动匹配 → 小红书笔记生成(调用 Dify 工作流或大模型)→ 审核并发送(模拟)。
另有「后台管理」(新闻源、提示词、商品库、客户画像、真实素材库、创作风格、文案规则、模型参数)和「评测台」(用例、跑评测、历史与 A/B 对比)。

技术:原生 HTML / CSS / JS,没有第三方库,没有构建步骤。`/api` 下是三个 Vercel 函数:热榜抓取 `hot.js`、大模型代理 `chat.js`、Dify 工作流 `dify.js`。

## 这一版的业务内容
- **商品**:西班牙语系统课(零基础到 B1)、预科(一年)、DELE 考前备考班、B1 冲刺班。价格库里没有,所以留空,**文案里不许出现任何价格**。商品清单请以 Dify 知识库为准,在后台「商品库」里增删改。
- **同一个商品对应多个客户画像**,不为人群新增商品。7 类画像:准大一新生、高考生/家长、留学本科、留学硕士、兴趣上班族、想转行的上班族、小学生家长。
- **真实素材库**(8 张卡):默认不用,新闻话题命中某张卡的“只用于”关键词才带上,只能写“可以写”里的内容。
- **文案规则**:广告法违禁词与绝对化承诺、正文和标签不写品牌名、不编造稀缺感/个人经历/学员案例、不自问自答、标题 ≤ 20 字;含西班牙语、数字、【待核对】只提醒人工核对。
- 新闻是“演示快照”(示意性的虚构标题);线上用“立即抓取”会尝试抓微博/百度热搜,抓不到就退回快照。

## 部署到 Vercel
1. 把整个文件夹放进 GitHub 仓库根目录(不要放 `.env`)。
2. 在 Vercel 点 **Add New → Project**,导入这个仓库。Framework Preset 选 **Other**,不用填构建命令。
3. 在 **Settings → Environment Variables** 添加(改完要 **Redeploy**):

| 变量 | 用在哪 | 说明 |
|---|---|---|
| `DIFY_API_KEY` | Dify 工作流 | Dify 应用「访问 API」里创建的密钥(`app-` 开头)。**不要发给任何人,不要写进代码** |
| `DIFY_BASE_URL` | Dify 工作流 | 选填,默认 `https://api.dify.ai/v1` |
| `ACCESS_CODE` | 两个接口通用 | 建议设置:前端必须带访问码才能调用,防止链接被他人刷额度 |
| `RATE_PER_MIN` | 两个接口 | 每个 IP 每分钟最多次数;`/api/dify` 默认 5,`/api/chat` 默认 20 |
| `LLM_API_KEY` `LLM_BASE_URL` `LLM_MODEL` | 大模型代理(选填) | 只有用「服务端代理」模式时才需要,默认 DeepSeek |

4. 打开站点 → 后台管理 → 模型参数 → 选「Dify 工作流」,填 Dify 开始节点的变量名和访问码,点「测试连接」,再点「用示例热点真跑一次工作流」。

> `vercel.json` 里给 `/api/dify` 设了最长 300 秒(一次工作流可能跑 1~3 分钟)。如果部署时报 maxDuration 超限,把 `300` 改成 `60` 再部署(工作流超过 60 秒会被切断)。

## 连接 Dify 工作流
工作台负责:选热点(风险识别)→ 选商品 → 选画像 → **调用 Dify** → 校验 → 人工审核。Dify 负责:写文案。提示词只在 Dify 里维护一份。

1. **Dify 里**:打开工作流应用 →「开始」节点 → 增加输入变量,变量名要和工作台后台「模型参数」里填的一字不差(例如 `query` 接热点标题;长内容的变量类型选“段落”)。可传的内容:热点标题/摘要/话题标签、客户画像名/全文、商品名/商品清单、真实素材、风格名、固定值。
2. **不要有“人工介入”节点**:接口调用遇到人工介入节点会一直等下去。你的工作流已改成 Agent 介入,没有这个节点,可以直接调用;人工审核由工作台 Step 5 完成。(如果以后又加了人工节点,需要加一个“API 模式”分支绕开。)
3. **结束节点**:输出变量名填到后台「输出变量名」(留空则自动取最长的文字)。输出里若有“审核说明”这类附带说明,把它的开头词填到“正文结束标记”,这之后的内容不参与校验。
4. **访问 API**:应用左侧「访问 API」→ 创建 API 密钥,填到 Vercel 的 `DIFY_API_KEY`。
5. Dify 模式下只调用一次(每次都会真的运行整条工作流,会用 Dify 和模型的额度);一键修正和评委打分不可用——Dify 的稿子请在 Dify 里改或在文本框里手动改。

## 配置怎么生效
- 后台保存的配置存在**访问者自己的浏览器**里(三级读取:本机浏览器 > `/data/config.json` > 内置默认,页面顶部有“数据来源”徽章)。
- 想让所有访问者都看到你调好的配置:后台点「导出配置」,把文件内容替换 `data/config.json`,重新部署。
- 评测历史也存在本机浏览器里。

## 注意
- 热搜抓取用的是公开热榜接口,**只适合原型演示**;正式使用应改用官方开放平台或商业舆情服务。
- 「一键发送」是**模拟**,不会真的发到小红书。
- 文案里的西班牙语、考试数字、政策,发布前仍要人工(西语老师)核对。
