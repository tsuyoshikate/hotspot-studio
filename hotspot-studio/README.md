# 热点营销工作台(HotSpot Studio · 演示版)

五步流水线:新闻抓取 → 建议匹配商品 → 商品库手动匹配 → LLM 文案生成 → 审核并发送(模拟)。
另有「后台管理」(新闻源、提示词模板、风格语调、文案规则、模型参数、商品库)和「评测台」(用例、跑评测、历史与 A/B 对比)。

技术:原生 HTML / CSS / JS,没有第三方库,没有构建步骤。`/api` 下是两个 Vercel 函数(热榜抓取、大模型代理)。

## 页面
| 页面 | 说明 |
|---|---|
| `/` | 工作台(Step 1~5) |
| `/admin.html` | 后台管理 |
| `/eval.html` | 评测台 |

## 本地预览(只看界面,用内置示例数据和「本地模拟」模式)
```
python3 -m http.server 8000
# 打开 http://localhost:8000
```
本地预览没有 `/api`,所以热搜抓取会失败并自动用「演示快照」兜底,大模型只能用「本地模拟」。

## 部署到 Vercel
1. 把整个文件夹上传到一个 GitHub 仓库(不要放 `.env`)。
2. 在 Vercel 点 **Add New → Project**,导入这个仓库。Framework Preset 选 **Other**,不用填构建命令,直接 Deploy。
3. 要让真实大模型可用,在 Vercel 项目的 **Settings → Environment Variables** 添加:

| 变量 | 必填 | 说明 |
|---|---|---|
| `LLM_API_KEY` | 是 | 服务商密钥(如 DeepSeek 的 `sk-...`)。只放在这里,不要写进代码 |
| `LLM_BASE_URL` | 否 | 默认 `https://api.deepseek.com/v1` |
| `LLM_MODEL` | 否 | 默认 `deepseek-chat` |
| `ACCESS_CODE` | 建议 | 设置后,前端必须带访问码才能调用,防止链接被他人刷额度 |
| `RATE_PER_MIN` | 否 | 每个 IP 每分钟最多调用次数,默认 20 |

改完环境变量后要 **Redeploy** 才生效。
4. 打开站点 → 后台管理 → 模型参数 → 接入方式选「服务端代理」,填访问码,点「测试连接」。

## 配置怎么生效
- 后台保存的配置存在**访问者自己的浏览器**里(三级读取:本机浏览器 > `/data/config.json` > 内置默认,页面顶部有「数据来源」徽章)。
- 想让所有访问者(比如 HR)都看到你调好的配置:后台点「导出配置」,把文件内容替换 `data/config.json`,重新部署。
- 评测历史也存在本机浏览器里。

## 注意
- 热搜抓取用的是公开热榜接口,**只适合原型演示**;正式使用应改用官方开放平台或商业舆情服务,并遵守对方的爬虫协议与服务条款。海外服务器可能被对方拦截,抓取失败时会自动用演示快照。
- 「一键发送」是**模拟**,不会真的发到微博。
- 函数有运行时长限制,所以暂不支持流式输出;视频/图片生成请走异步任务,不要放进同步请求。
- `/api/chat` 做了白名单(只转发到 `LLM_BASE_URL`)、访问码和简单限流,但仍然建议设置 `ACCESS_CODE`。
